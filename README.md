# matlabs_functions — utilidades en MATLAB

**En una frase:** pequeñas funciones de MATLAB para trabajar con generadores y conjuntos, y un modelo de optimización de carnes.

## Contenido
- `CarneOptima.m` — modelo de optimización (el más extenso del repositorio).
- `matriz_generador.m`, `uniongen.m`, `intergen.m` — construcción de matrices generadoras, y unión e intersección.
- `sumcond.m`, `promcond.m`, `promponcond.m` — sumas, promedios y promedios ponderados condicionales.

## Tecnologías
MATLAB
